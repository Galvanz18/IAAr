# IAAr

Kits de **conscientização intrusiva** (simulação de phishing autorizada) para
treinamento de segurança.

## Campanhas

- [`campaigns/device-code-m365/`](campaigns/device-code-m365/) — Campanha de
  **device code phishing** (Microsoft 365 / Entra ID) para rodar na **Cofense
  PhishMe**: e-mail isca (CEO/RH), página do código, página de submissão e
  simulador interativo do fluxo.

## Documentação

- [`docs/device-code-phishing.md`](docs/device-code-phishing.md) — Base técnica
  da técnica de device code, sinais de reconhecimento, detecção e mitigação.

---

> ⚠️ **Uso exclusivo em engajamentos autorizados.** Os materiais operam em modo
> conscientização: **não** coletam credenciais/tokens reais nem executam o fluxo
> OAuth real. Destinados a treinar colaboradores da própria organização, com
> autorização formal.
