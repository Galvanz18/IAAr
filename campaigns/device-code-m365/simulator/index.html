Simulador — Device Code Phishing (M365 / Entra ID)

Ferramenta didática de conscientização. Avance passo a passo para ver como o ataque funciona.

Ambiente de treino. Tudo aqui é simulado. Nenhuma chamada real é feita à Microsoft, nenhum código válido é gerado e nenhum dado é coletado. Os valores são fictícios e servem apenas para ilustrar o fluxo.

Vítima

Passo 0 / 5
1Atacante inicia o fluxo device code Pede um código ao provedor fingindo ser um dispositivo sem navegador.
2Provedor devolve o código de usuário Ex.: ABCD-EFGH + a URL microsoft.com/devicelogin.
3Atacante envia a isca à vítima "Digite este código para liberar seu acesso."
4Vítima digita o código na página real e autentica Login verdadeiro + MFA — e, sem saber, autoriza o dispositivo do atacante.
5Atacante recebe os tokens Acesso e refresh token: sessão persistente na conta da vítima.

🚩 Onde a vítima deveria ter parado

  • Recebeu um código sem ter iniciado nenhum login por conta própria.
  • A mensagem trazia urgência ("libere seu acesso agora").
  • Pedia para digitar o código em microsoft.com/devicelogin a partir de um link/e-mail.

Regra de ouro: um login iniciado por você nunca chega pronto na sua caixa de entrada. Nunca digite em microsoft.com/devicelogin um código recebido de alguém.
